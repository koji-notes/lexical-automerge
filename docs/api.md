# API reference

The package root exports the binding, schema version 2 document helpers
(`createLexicalAutomergeDocument`, `syncDocument`, `migrateDocument`), the
optional `AutomergeBlockNode`, and presence. Diff and reconciliation helpers
stay internal.

React integrations are available from `@koji-api/lexical-automerge/react`.
Presence is also available from `@koji-api/lexical-automerge/presence`.
